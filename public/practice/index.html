How JLPT N5 practice works

JLPT Quiz separates vocabulary, grammar and reading, and listening so you can target one skill or mix all three. Each Japanese question includes hiragana readings beside kanji. Practice mode offers an optional English reveal, immediate checking, and a short explanation. It is designed for study rather than exam simulation, so there is no countdown timer.
